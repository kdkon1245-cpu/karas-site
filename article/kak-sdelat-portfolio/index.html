Как сделать сайт-портфолио: от контента до своего домена

Как собрать свой сайт с помощью нейросети, без кода и конструкторов: контент, референсы, промты, мобильная версия и публикация на свой домен.

1. Введение

Behance и Dprofile — удобные площадки, но там ваши работы всегда живут в чужой сетке, рядом с чужими кейсами. Свой сайт — это витрина, которая выглядит как ваш бренд: ваши шрифты, ваш цвет, ваша подача. Раньше для этого нужен был разработчик или конструктор с шаблонами, сейчас хватит нейросети Claude: она пишет код, а вы ставите задачи и правите результат, как арт-директор.

В этой статье разберём весь путь по шагам: от сбора контента до сайта на своём домене. На каждом шаге — готовый промт, который достаточно скопировать в Claude.

3. Контент

Начинайте не с дизайна, а с контента. Пока его нет, вы рисуете пустые рамки и не понимаете, сколько у вас проектов и сколько текста. Соберите в одну папку:

РазделЧто подготовитьСовет
ПроектыОбложка, 5–15 слайдов, название, подзаголовок в одну строку, год, клиент, тегиОбложки — в одной пропорции
О себеПара абзацев, фото, список услуг, контактыПишите так, как говорите с клиентом
Отдельные работыПлакаты, иллюстрации — картинки в одном формате, название, серияНужны, если хотите отдельную галерею

Если проекты уже лежат на Behance или Dprofile, вручную ничего переносить не нужно — Claude заберёт их по ссылке.

Промт для Claude

Мои проекты лежат здесь: (ссылка на Behance / Dprofile). Забери тексты и картинки всех проектов и разложи их в папке сайта: у каждого проекта — обложка, слайды, название, подзаголовок, год, клиент, теги. Обложки приведи к одной пропорции. Потом покажи список: чего не хватает.

Важно! Обложки в одной пропорции — это не прихоть. Иначе сетка проектов поедет, а часть картинок обрежется.

4. Референсы

Референсы — самая важная часть задачи для нейросети. Просьба «хочу, чтобы работы красиво листались» почти всегда превращается в обычный слайдер. Скриншот и одна фраза о том, что из него взять, работают в разы лучше.

Главный референс — ваш собственный бренд: логотип, фирменные цвета и несколько работ. Соберите их в один фрейм — из него нейросеть возьмёт характер для всего интерфейса. Остальные референсы — это механики: как листаются работы, как устроен первый экран.

Тип референсаЧто берёмПример у меня
БрендЦвета, шрифты, графические элементыФрейм с логотипом и плакатами
МеханикаКак работы листаются и двигаются3D-стопка, круговая карусель
КомпозицияКак разложены блоки на экранеСетка проектов по две в ряд
НастроениеСвет, фактура, подачаФонарик на тёмной сцене

Берите 3–5 референсов, не больше, и к каждому пишите, что именно из него взять. Референс — это не «сделай копию»: всё должно быть в вашем стиле.

5. Первая версия

Когда контент и референсы готовы, отправляем Claude стартовую задачу. Если вы используете универсальный промт — этот шаг он сделает сам. Если хотите начать вручную:

Промт для Claude

Помоги мне сделать сайт-портфолио. Я (профессия) из (город), мой бренд — (название). Разделы: главная (первый экран, избранные проекты, обо мне, контакты), все проекты, страница проекта.

Стиль: (3–5 слов про бренд). Цвета: (коды). Шрифты: (названия). Референсы и контент — в папке.

Сайт должен быть простым: обычные страницы на HTML, CSS и JavaScript без конструкторов, чтобы его можно было бесплатно разместить в интернете. Нужна мобильная версия. Новые проекты я хочу добавлять сам, не трогая дизайн. Сначала покажи план, потом сделай первую версию и покажи скриншоты на компьютере и телефоне.

Важно! Первая версия будет далека от идеала, и это нормально. Нейросеть соберёт рабочий сайт, но вкус, детали и характер — это ваша работа на следующем шаге. Не расстраивайтесь и не начинайте заново: дорабатывайте то, что есть.

Как это было у меня

Сначала главная встречала коллажем из работ под «фонариком». К столу с реальными предметами я пришёл только после десятков правок.

6. Доработка

Дальше работа похожа на переписку с разработчиком, только он отвечает за минуту. Чтобы правки срабатывали с первого раза:

Суть«Сделай отступ 24 px и шрифт 18»«Заголовок тесно прилип к шапке» — решение нейросеть найдёт сама

Промт для Claude

Посмотри скриншот. Что не так: (1. …, 2. …, 3. …). Исправь, затем сам открой страницу на компьютере и на телефоне и проверь, что ничего не поехало. Если решение спорное — предложи два варианта.

7. Мобильная версия

Большинство откроет ваше портфолио с телефона, по ссылке из мессенджера. Проверяйте сайт на своём телефоне, а не в узком окне браузера.

Промт для Claude

Проверь сайт на ширине телефона и исправь по списку: шапка, проекты по две в ряд, кнопка «вниз» на первом экране, свайп в каруселях, крупные кнопки. Покажи скриншоты до и после.

Если делаете светлую тему, проверьте её отдельно: яркий акцентный цвет на светлом фоне часто не читается.

Проверь все страницы в светлой теме. Акцентный цвет (код) на светлом фоне не используй: заливки сделай тёмными, акцентный текст и линии — тёмными. Покажи список мест и исправь.

8. Публикация

Сначала разберёмся, как сайт попадает в интернет. Схема простая, и настраивается она один раз:

8.1 Подготовка

Перед выкладкой нужны мелочи, без которых сайт выглядит недоделанным: картинка-превью для ссылки в мессенджерах, иконка во вкладке браузера и страница «404» на случай неправильной ссылки.

Промт для Claude

Подготовь сайт к публикации на домене (адрес): превью для соцсетей и Telegram на всех страницах, иконка сайта, страница 404, sitemap.xml и robots.txt. Напиши скрипт, который собирает чистую копию сайта для публикации — без черновиков и служебных файлов.

8.2 GitHub

  1. Зарегистрируйтесь на github.com.
  2. Создайте публичный репозиторий — это папка проекта в облаке.
  3. Установите GitHub Desktop и войдите в аккаунт.
  4. Скопируйте репозиторий к себе на компьютер (кнопка Clone).
  5. Соберите в эту папку сайт и нажмите в GitHub Desktop Commit, затем Push.
Промт для Claude

Я зарегистрировался на GitHub и установил GitHub Desktop. Проведи меня по шагам: как создать репозиторий для сайта, куда его склонировать, как собрать туда сайт и отправить его кнопками Commit и Push.

8.3 Хостинг

App Platform в Timeweb Cloud сам забирает сайт с GitHub и выкладывает его в интернет. Нажали Push — через минуту сайт обновился.

  1. В панели Timeweb Cloud откройте App Platform → Добавить → GitHub.
  2. Разрешите доступ только к репозиторию с сайтом (Only select repositories).
  3. Тип — Frontend, фреймворк — HTML/CSS/JS, регион — Москва, тариф — минимальный.
  4. Дождитесь статуса «Успешно» и откройте технический адрес вида что-то.twc1.net.
Промт для Claude

Помоги разместить сайт на Timeweb Cloud App Platform из моего репозитория GitHub (название). Проведи по шагам: какие настройки выбрать, как включить автодеплой. Если деплой упадёт — я пришлю скриншот логов, разберись.

8.4 Домен

  1. Найдите свободный домен и оплатите — удобнее там же, в Timeweb. Для .ru понадобятся паспортные данные.
  2. В настройках приложения добавьте домен.
  3. Включите бесплатный SSL-сертификат, чтобы сайт открывался по https.
Промт для Claude

Я купил домен (адрес). Помоги привязать его к приложению в Timeweb App Platform и выпустить SSL. Если сайт не открывается — проверь по порядку: деплой, технический адрес, DNS, SSL — и скажи, где проблема.

Важно! Новый домен начинает открываться не сразу: от 15 минут до нескольких часов. У меня ушло около полутора часов — не паникуйте раньше времени.

Если прошло несколько часов, а сайт так и не открылся, проверьте по порядку:

9. Вывод

Свой сайт больше не требует знания кода или бюджета студии. Нужны собранный контент, хорошие референсы и терпение на десятки правок. Код берёт на себя нейросеть, выкладку — GitHub и Timeweb, а за вами остаётся главное: вкус и арт-дирекшн.

  • Начинайте с контента, а не с красоты.
  • Показывайте референсы и скриншоты вместо длинных описаний.
  • Первая версия всегда сырая — дорабатывайте, а не начинайте заново.
  • Проверяйте сайт на реальном телефоне.
